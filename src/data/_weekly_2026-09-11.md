## TL;DR
- 本周主线是「动作怎么被表示与约束」，而且内部在打架：FreqFM（AGIBOT）与 Time-Frequency Geometric Cross-Attention（2609.09925）站在一边，认定 action chunk 是一段短时多变量轨迹、时域均匀建模浪费了频率结构；FiberTune（UCAS）从另一侧补刀，指出动作监督微调只约束「改变动作的方向」，放任动作等价状态的视觉结构沿 local action fiber 崩塌。三者合起来说明：action chunk 的隐空间不该按逐时间步 token 处理。
- 反方只有一条但很硬：Show-Harness 直接绕过端到端 VLA——让通用 VLM 通过离散语义动作单元 + 本体特定解释器「玩」机器人。若这条路走通，本周所有动作头频率化的功夫都可能被整体绕开，这是本周最尖锐的分歧。
- 工程侧两条都在打「真机后训练太贵」：RoboDrop 用局部梯度兼容性筛数据，HaWMPO 用世界模型 + 幻觉感知的在线 RL 替代物理交互。基准侧则出现裂缝——CALVIN/LIBERO 已被压到 +0.00/+0.03（PriorVLA 与 VLAFlow 持平），FolDeX 却指现有真机基准只覆盖短程刚体、管不了长程可变形操作。

## Spotlight
### [Frequency-Conditioned Flow Matching for Vision-Language-Action Models (FreqFM)](https://arxiv.org/abs/2609.10405)
动作是时间上高度相关、各频段能量高度非均匀的轨迹，而 Flow Matching 式 VLA 一律在时间坐标里均匀生成动作；FreqFM 按频段条件化生成动作，显式建模这种频率异质性。

这篇的分量在于把「动作块怎么生成」的默认设定重新打开：一段 action chunk 是平滑全局趋势叠加细粒度纠错分量，二者频段能量高度非均匀，而 time-domain 均匀 denoising 等于对这个结构不做区分。按频段条件化相当于给 flow matching 注入一层频率先验，是对动作头的最小侵入式改动——这正是它被候选数据标为 🔧（可复用其频率条件化流匹配动作头）的原因。它与同期 Time-Frequency Geometric Cross-Attention 是同一觉悟的两种实现，候选数据明确标注两者「同组且思路重叠」。张力来自反方向：Show-Harness 不走 VLA，让通用 VLM 通过离散语义动作单元、由本体解释器确定性执行——若成立，频率条件化这类动作头优化会被绕开。取舍与未知：频段如何划分、条件注入在哪一层、训练与显存开销、能否真正抬高跨基准数字，摘要均未给 > TODO: 需查证。团队 AGIBOT。

> 用最小改动把动作头从时域均匀生成换成频段条件化，是本周最容易直接抄的升级；先复现其条件注入方式再看数字。

### [RoboDrop: Curating VLA Post-Training Data via Local Gradient Compatibility](https://arxiv.org/abs/2609.10021)
VLA 后训练数据常混有执行错误、传感器噪声等异质误差，RoboDrop 用「局部梯度兼容性」自动筛出既适配新任务/新本体、又不破坏预训练能力的数据。

后训练与预训练目标不同——前者要任务/本体特化，因此对数据质量远比预训练敏感；而实际采集的数据一定混着执行错误与传感器噪声等异质误差，靠人工清理不可扩展。RoboDrop 的落地点是把「数据好不好」算成一个局部梯度兼容性指标，直接插进现有微调管线做自动过滤，低风险高回报（候选标 🔧）。它与本周 HaWMPO 构成本条线的两端：一个管「用哪些数据」，一个管「在模型里怎么练」——HaWMPO 用世界模型 + 幻觉感知的在线 RL，正是为了替代昂贵、低样本效率且有硬件风险的物理交互。代价：局部梯度兼容性通常依赖参考梯度/参考集，在小样本或强分布偏移下是否稳健、开销多大，摘要未给 > TODO: 需查证。团队清华 / Striding AI。

> 把后训练数据筛选做成可自动化的梯度判据，是最容易本周就接进自家微调流程的一件工程活。
