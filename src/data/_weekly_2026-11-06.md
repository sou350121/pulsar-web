# VLA 週報 | 2026-10-31 to 2026-11-06
> 基於 VLA-Handbook 7 天系統數據

## TL;DR
- LeRobot v0.7.0 把训练栈整体重建到面向 5-20B world-action model：FSDP2/HSDP/Torch DCP、近 300TB 开放数据流式训练、interactive rollout 与远程 policy server——开源侧第一次给 WAM 级训练提供了完整基建。
- 触觉 VLA 出现两条互补路线：VTAM 用视觉-触觉 world-action model 绕开大规模触觉预训练，社区侧 PHYMI Sagi 与 Archon 的 demo 把触觉+形变操作推向真实场景，但均缺量化数据。
- RL 后训练的世界模型路线（WoVR）与失败-纠正数据合成（OopsieRecover、DenseReward）共同指向同一个判断：VLA 能力提升的瓶颈已从架构挪到数据与训练信号。
- CALVIN/LIBERO 榜单继续被 4.6-4.8 avg_len 与 99%+ 的饱和数值占据，评测区分度是本周最被低估的问题。

## Spotlight
### [VTAM: Efficient Visuo-Tactile World-Action Models for Contact-Rich Manipulation without Tactile Pretraining](https://arxiv.org/abs/2603.23481)
UIUC 提出的视觉-触觉 world-action model，面向接触丰富操作，显式使用触觉信号，但不需要大规模触觉预训练，也不需要动作预训练，同时控制迭代式视频生成带来的推理延迟。

这篇是本周最贴合我们主线（触觉+VLA）的工作。它同时戳中现有触觉 WAM 的三个痛点：触觉被弱利用（只当额外视觉通道）、依赖大规糢触觉预训练数据（而这批数据几乎不存在公开集）、以及 world model 的迭代视频生成导致延迟不可接受。VTAM 的核心取舍是——用视觉-触觉联合的 world-action 建模提供接触状态的预测性表征，从而把『触觉先验』从数据依赖转移为建模结构依赖。工程价值判断：如果它的无触觉预训练设定在真机上站得住，那么触觉 VLA 的最贵那道门槛（触觉数据采集规模）就被绕开了，这对我们团队是直接可用的路线，而不是读一读的路线。需要警惕的一点是摘要未给出跨硬件的触觉泛化证据——触觉传感器的标定与跨本体差异，恰恰是触觉 VLA  historically 最难迁移的部分，建议跑它的消融表，特别关注换传感器后性能衰减。本周 community 侧的两个触觉 demo（Archon 的 AirPods/布料、PHYMI 的接触空间高频力-触觉反馈）都只是宣传材料、无方法论文，所以 VTAM 这类有方法有对照的学术工作才是当下唯一可信的技术参照。

### [WoVR: World Models as Reliable Simulators for Post-Training VLA Policies with RL](https://arxiv.org/abs/2602.13977)
中科院自动化所的工作，把学到的 world model 当作仿真器，让 VLA 策略在闭环想象 rollout 中做 RL 后训练，从而避开海量真机交互；重点解决想象 rollout 的幻觉与长程误差累积。

RL 后训练在 VLA 上的落地障碍从来不是算法，而是『有足够的真实交互』。WoVR 选择的路线是用 world model 替代真机，这跟你团队 VLA 后训练的方向直接对口。它值得单独拎出来分析的原因不是『又一篇 world model + RL』，而是它把问题定位在可靠性上——闭环想象一长就漂、漂了就学歪，于是核心贡献变成如何让 imagined rollout 的误差不累积到破坏策略优化。这个 framing 比『用 world model 做 RL』本身有价值得多。与本周另外两篇一起看更有意思：DenseReward（合成失败轨迹训练密集视觉语言奖励模型）解决的是奖励信号稀疏，MAC-v2（Berkeley/Levine，像素输入下的长程值展开）解决的是像素域值估计，三篇拼起来是一条完整的『不碰真机做 RL 后训练』链路：world model 给环境，dense reward 给信号，value expansion 给长程信用分配。工程落地判断：world model 的保真度上限决定了后训练效果上限，如果真机验证只是小幅优于 SFT，那这套流程的复杂度就不划算。

## SOTA 變化
- **CALVIN (ABC-D avg_len)**: MMaDA-VLA 4.78、AVA-VLA 4.65、NS-VLA 4.56、EDAR (ABCD-D) 4.75、HiMoE-VLA (D-D) 4.49 同期上榜，头部区间拥挤在 4.5-4.8
  - avg_len 天花板逼近 5.0，榜单增量已进入 +0.1~+0.3 的微调区间，新工作越来越难靠 CALVIN 长程指标拉开实质差距。
- **LIBERO (average)**: LaST-R1 99.8（opensource 分组）、FutureDuet 99.2（standard-closed）、PLD 99.17（non-standard）三线均破 99%
  - LIBERO 在开源权重赛道已基本饱和，99%+ 数值不再具备区分度，后续比较需转向扰动/分布外设置（这也解释了为什么本周出现 BURGER 这类泛化压测基准）。
- **LIBERO Plus (non-standard, total)**: CorridorVLA 83.21，较 NS-VLA 基线 +3.81
  - LIBERO Plus 仍留有 3-4 个点的可争取空间，是目前少数还能反映方法差异的变体基准，值得作为主报告指标。
- **社区侧反向信号（OpenVLA Issue #303）**: 用户报告夹爪预测偏差达 46%（13 条评论、约 4 人参与），指向标定与精度问题
  - 榜单上的 99% 与真机上的 46% 偏差同周出现，这是本周对 SOTA 叙事最有力的反驳证据——benchmark 饱和不等于能力饱和。

## 下週觀察清單
- VTAM 若放出真机与跨触觉传感器消融数据，将直接决定『无触觉预训练』是否可信；重点看换传感器后的性能衰减曲线，而非均值。
- LeRobot v0.7.0 的 breaking changes 会在社区 issue 里集中爆发（训练栈重建 + policy-server 新接口），下週 lerobot 摩擦点大概率从 train 向 install/deploy 迁移，值得盯 DFI 变化。
- WoVR / DenseReward / MAC-v2 这条『不碰真机做 RL 后训练』链路是否出现端到端整合工作，如果下周有论文把 world model 仿真器 + 密集奖励 + 长程值展开串起来并在真机验证，会是本季度最重要的方法论收敛。
- 榜单饱和反噬：LIBERO 99%+ 之后，是否有主流工作开始主动报告扰动/分布外设置的成绩；BURGER、反事实指令评测（Vision Overrides Language）这类泛化压测基准是否被更多论文引为常规报告项。
- VLA 部署侧的安全与运行时监控（VLA-Tug 的校准潜空间失败预测、ActQuant 的 sub-4-bit 权重量化）能否形成一套可组合的边缘部署方案——量化压显存、探针保安全，这两件在本周同时出现不是巧合。
